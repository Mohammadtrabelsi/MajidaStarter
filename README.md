# MajidaStarter

MajidaStarter is a batteries-included **Laravel 13 + Livewire 4** starter kit for building content sites and admin-driven web apps.

The documentation is available in three languages:

| Language | Main guide | Docker guide |
| -------- | ---------- | ------------ |
| 🇬🇧 English | [docs/en/README.md](docs/en/README.md) | [docs/en/README.docker.md](docs/en/README.docker.md) |
| 🇫🇷 Français | [docs/fr/README.md](docs/fr/README.md) | [docs/fr/README.docker.md](docs/fr/README.docker.md) |
| 🇸🇦 العربية | [docs/ar/README.md](docs/ar/README.md) | [docs/ar/README.docker.md](docs/ar/README.docker.md) |

Other project documentation:

- [docs/spatie-integrations.md](docs/spatie-integrations.md): slugs, SEO, tags, RSS, honeypot, backups, health, PDF and spreadsheets
- [docs/feature-audit-and-improvements.md](docs/feature-audit-and-improvements.md): feature audit and improvement backlog

## Quick start

```bash
composer setup
php artisan db:seed
composer dev
```

Requires PHP 8.4 and Node.js 20. See the main guide for details.
