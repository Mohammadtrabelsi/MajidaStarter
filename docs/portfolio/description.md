# MajidaStarter: portfolio description

**Image:** `banner.png`
**One line:** A Laravel 13 and Livewire 4 starter kit with authentication, two-factor login, an admin panel and access control ready from day one.

**CV (short):** Open starter kit for Laravel 13 and Livewire 4 with two-factor authentication, role-based access control, an admin panel, activity logging, a content module, a REST API and LTR/RTL support.

**Portfolio:** MajidaStarter removes the boilerplate from new projects. It ships with sign-in and two-factor authentication, an admin back office with roles and permissions, an activity log, a blog-style content module, a REST API, light and dark themes, and LTR/RTL layouts, so teams can start on their own features immediately.

**Stack:** Laravel 13, Livewire 4, Spatie permissions and activity log, REST API
